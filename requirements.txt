# Vepol Python dependencies.
#
# Installed once per user into the python3 on your PATH, with the pip line
# under "After install" in README.md:
#   python3 -m pip install --user -r requirements.txt
# (Homebrew's Python: --break-system-packages in place of --user.) The kb-*
# commands run that python3, so a separate venv is not seen. Used by Vepol
# modules that need Python beyond the standard library.
#
# Modules that need these:
#   - People  → python-frontmatter, click, PyYAML, jellyfish
#   - Daily NotebookLM research → notebooklm-py (CLI command: notebooklm;
#     for scheduled runs install it with `pipx install notebooklm-py`)
#   - Daily-plan generator → standard library only (no extras)
#   - Evolution Loop → PyYAML
#
# External sources are read without vendor SDKs or OAuth client libraries
# in Vepol's code: the calendar through Claude Code's MCP connector
# (`claude -p`), mail through `codex exec` and Codex's Gmail plugin. The
# one direct client is Telethon, for Telegram, which signs in with your own
# Telegram account. See docs/methodology/mcp-first-sources.md.
#
# When adding a Python dependency, pin a known-good version range and
# add a one-line note about which module needs it.
