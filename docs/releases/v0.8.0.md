# v0.8.0 — Morning audio speaks your whole brief

Your morning audio now voices the *whole* finalized morning brief, the whole
eligible same-day arXiv report, and the whole Money Radar digest — in that
order, with no second summarization pass in between. What you hear is exactly
what was written for you that morning.

## What you get

- **No lossy re-synthesis.** Previous releases generated digest text with a
  second synthesis pass over the morning inputs. Now the finalized blocks are
  frozen and passed through as-is: local Qwen narrates them literally, and
  NotebookLM receives the same frozen source for its own Audio Overview.
- **Freshness checks at both ends.** `kb-brief-preflight` feeds the brief
  generator a project-freshness report before the brief is written, and the
  digest voices a morning brief only when it is finalized and same-day; a
  missing or stale block is skipped honestly instead of being papered over.
- **Quiet days stay quiet.** When arXiv has no new papers, you get a short
  text notice and no filler audio block.

## Reliability work that rode along

- The shipped test suite now tests the code in this repository instead of
  whatever hub happens to be installed on the machine (`KB_CYCLE_SRC_BIN`
  overrides the source tree when you *want* to test an installed copy).
  `tests/run-all.sh` is green end to end from a clean checkout.
- Fresh installs without the optional Codex CLI pass
  `kb-doctor install-health --strict` out of the box.
- The whole-block audio test's documentation check now polices current docs
  only; shipped release notes are treated as immutable history.

## Upgrading

Pull the release. No configuration or data changes. If you had scheduled
morning audio configured, it starts using whole-block composition on the next
morning run.
