# v0.7.1 — Stock-Python reliability fix

A small patch release with one job: Vepol now starts correctly on the Python
that macOS ships out of the box. No features, no behavior changes — seven
files gain one line each.

## What was broken

macOS provides Python 3.9 as `/usr/bin/python3`. Scheduled jobs — LaunchAgents,
cron entries, session hooks — often run with a reduced `PATH`, so a bare
`python3` resolves to that system interpreter even on a machine where a newer
Python is installed for interactive use.

Seven files used modern type annotations (`str | None`) that Python 3.9
evaluates the moment the file loads. On the system interpreter they crashed
with a `TypeError` before any code ran:

- **`kb-planner`** — the daily planner is launched directly by its LaunchAgent
  at 00:05; under a reduced `PATH` it could not start at all.
- **`kb-session-start`** — the session hook exited with an error and no
  output, so a new agent session lost its entire startup context bundle.
- **`kb-task`** — failed on invocation.
- **the four contact-notebook modules** — the People Notebook pipeline could
  not be imported.

## The fix

Each file gains one line — `from __future__ import annotations` — which makes
those annotations lazy, so the same source runs on Python 3.9 and later. An
AST sweep of the whole `bin/` tree (106 Python files, 39 extensionless Python
executables, 124 embedded Python heredocs) confirms no other file has the same
problem.

## Verification

- Before, on a clean checkout with `env -i PATH=/usr/bin:/bin`:
  `kb-session-start` exits 1 with no output; `kb-planner` and `kb-task` raise
  `TypeError`; the contact-notebook modules fail to import.
- After, on the same interpreter: the session hook prints its full startup
  bundle, the planner loads, `kb-task --help` prints usage, and the modules
  import cleanly.
- The startup-context suite and the three contact-notebook suites pass
  (23/0, 35/0, 13/0).

## Upgrading

Pull the release and re-run `./install.sh --apply` (or copy `bin/` per your
setup). No configuration, data, or manifest changes are involved.
