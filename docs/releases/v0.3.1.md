# Vepol v0.3.1 — Startup Context, Install Hardening, Money Radar

Vepol v0.3.1 is a patch release that packages the useful post-v0.3.0 work
already sitting in Git and the local seed: safer installs, better session
startup context, a split learning digest pipeline, and a complete opt-in Money
Radar seed package.

## What Ships

- Prompt-first install flows for agent-assisted setup, verification, apply,
  uninstall, and upgrade.
- Installer verification/self-heal fixes for the `orchestrator-seed` pointer.
- `kb-session-start` startup manifests with agent card, state, recent log,
  active work, escalations, and compact incident rules.
- `kb-learning-arxiv` v3 manifests: Codex handles translation/method summaries;
  Grok handles only X/Twitter + Reddit social context.
- `kb-retro` reads markdown `kb-board` files instead of Plane.
- `kb-money-radar`, disabled by default, with runner, process default, and
  tests shipped together so no seed references are dangling.
- Owner-approved specification gate documentation and hardened templates.

## Upgrade Notes

`kb-money-radar` is present but disabled. To use it, first personalize
`~/knowledge/personal/money-radar.yaml`, then enable the `money-radar` process
in `personal/processes.yaml`.

`kb-learning-arxiv` rewrites older successful manifests to v3 when it needs the
new method/setup fields. This is intentional; old v2 cache hits are not enough
for the new digest contract.

## Verification

The release was assembled from a clean `origin/main` worktree and verified with
focused startup-context, learning, Money Radar, syntax, diff-check, and
leak-scan gates before tagging.
