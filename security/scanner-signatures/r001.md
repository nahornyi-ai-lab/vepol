# Scanner signature catalogue — r001 (genesis)

Immutable per-revision catalogue. Per spec § Catalogue location and protocol,
this file is referenced by `current.yaml` and anchored in
`~/knowledge/security/scanner-signatures-ledger.md`. Both the file bytes
hash and the ledger chain must match at runtime; mismatch → fail-closed.

**All trippable pattern bodies are stored base64-encoded** per spec PATCH 3
to prevent self-injection when LLM reviewers read this file. The scanner
decodes at load time for matching.

Format per signature:

    ## sig-X-NNNN
    ```yaml
    family: A..E
    pattern_label: <kebab-case-label>
    pattern_encoding: base64 | plain
    pattern: <encoded body>
    match_type: literal-case-sensitive | literal-case-insensitive | regex | regex-codepoint-class
    severity: low | medium | high | critical
    default_verdict: flagged | refused
    added_date: YYYY-MM-DD
    source_ref: <citation>
    notes: |
      <human-readable rationale>
    ```
